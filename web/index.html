Ask the RAG papers

Search 60 arXiv papers on retrieval-augmented generation. Keyword search and vector search run side by side, their results are merged, then a reranker picks the best five. Everything runs in your browser.

How each step ranked these passages

Position in each list (blank = not in that list's top 50). Merging rewards passages that both searches liked; the reranker then reads each passage together with your question.

How it works

  1. 60 papers were split into 1,868 passages of about 250 words, each tagged with its paper title.
  2. Keyword search (BM25) finds passages that share your exact words, which is good for names like FLARE or Ragas.
  3. Vector search (bge-small embeddings) finds passages that mean the same thing in different words.
  4. Reciprocal Rank Fusion merges the two top-50 lists using ranks only, so their scores never need a common scale.
  5. A cross-encoder reranker reads your question and each of the top 30 passages together and keeps the best 5.
  6. The example questions show a real answer Claude wrote from those 5 passages, with citations. For your own questions this page quotes the closest sentences instead, so it runs free with no server.

Measured

Share of test questions where the right paper was in the top 5, measured on this page's own code and models. The reworded set avoids the papers' own wording.
